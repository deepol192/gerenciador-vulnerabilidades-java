# Sistema de Gerenciamento de Vulnerabilidades 🛡️

Este é um projeto prático desenvolvido em **Java** com foco na integração de conceitos de **Programação Orientada a Objetos (POO)** e diretrizes fundamentais de **Cybersecurity** e **Linux**.

## 🚀 Funcionalidades
- Cadastro de falhas de segurança com identificadores padrão (CVE).
- Classificação de severidade de risco (Baixa, Média, Alta, Crítica).
- Relatório em tempo real via terminal de comandos (CLI).

## 🛠️ Tecnologias Utilizadas
- **Java SE** (Lógica, Estruturas de Repetição e Coleções de Dados com ArrayList).
- **Git & GitHub** para controle de versão.

## 📖 Como Executar (via Terminal Linux)
1. Clone o repositório: `git clone https://github.com`
2. Compile o arquivo: `javac Main.java`
3. Execute o programa: `java Main`
